中学理科　しあげ

余裕があれば記述式に挑戦！

理由を聞かれたら、点がとれる書き方がある。書く → 答え合わせ → 自分で ○△× をつける。

書き方の3か条

  1. 聞かれたことだけに答える。「理由」なら、文末は「〜から」「〜ため」。
  2. 採点ポイントのキーワードを入れる。1つ入るごとに点がつく。
  3. 1文で短く書く。わからなくても空欄にしない。近いことを書けば点がつくことがある。

どの学校のテストにも出る型。ここは全員、満点をとりたい。

○ 0 / 4

表や図を読んで、ことばを組み合わせて書く問題。平均より上の点は、ここで差がつく。

○ 0 / 4
記録はこの端末のブラウザに保存されます。消したいときは、各問題の「書きなおす」を押してください。
